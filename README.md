# UAB-Decision-Making

## Env

- Python version: 3.11.13
- Requirements: `requirements.txt`

## Dataset

Create in the root repository a folder with the name `dataset`.

````
__ UAB-Decision_Making
  |__ dataset
     |__ sample (here are the date from "Description and Sample of the DataSet")
     |  |__ LUNA16_Dataset_Description.pdf
     |  |__ MetadatabyAnnotation.xlsx
     |  |__ CT
     |     |__ image (all the CT images)
     |     |__ nodule_mask (all the masks)
     |     
     |__ full (here are the data "from Full DataSet")
        |__ MetadatabyAnnotation.xlsx
        |__ VOIs
           |__ image (all the CT images)
           |__ nodule_mask (all the masks)
````
